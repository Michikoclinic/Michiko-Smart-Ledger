# Michiko Smart Ledger

Michiko Smart Ledger is a digital Daily Ledger for an aesthetic clinic. It preserves the readable, narrative workflow of reception's handwritten book while adding automation, traceability, and auditability.

The Daily Ledger is the core product. This project is intentionally not an accounting system, ERP, or bookkeeping product.

## Current status

The repository is documentation-first. No business features have been implemented yet. The next development step is Domain Model review—not UI coding.

Implementation must not begin until the documentation has been reviewed and approved by the relevant clinic and engineering stakeholders.
